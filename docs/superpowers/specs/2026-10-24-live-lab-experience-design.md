# Live Lab Experience Design

## Intent

Give employers a more visual, experience-first view of Don Lopez's completed cybersecurity coursework and lab work. The portfolio should make the Kali, VMware, Wireshark, Snort, Splunk, E3 and network-analysis experience easy to understand without presenting a third-party reference image as an original lab capture.

## Goals

- Present the owner-confirmed Kali/VM/network work as completed hands-on experience rather than a proposal or future demonstration.
- Add network work prominently: isolated VM activity, packet capture, traffic review, Snort tuning and the connection into Splunk investigation.
- Add two more real CSUSB photographs to the academic experience.
- Create a compact visual evidence gallery using genuine existing portfolio captures and reproducible public network artifacts.
- Keep the homepage and employer-choice page fast to scan.

## Non-goals

- Do not invent exact commands, IP addresses, timestamps, findings or assignment outcomes that are absent from the résumé, transcript and owner confirmation.
- Do not relabel reference photographs or conceptual diagrams as original lab evidence.
- Do not change the three separately planned phishing, identity/MFA and SOC automation briefs.
- Do not alter either résumé PDF or publish the private transcript.

## Chosen approach

Use an experience-first casebook. Update the existing Kali defender-visibility case into a completed isolated VM and network-visibility case rather than adding a duplicate route. Pair a real Kali reference screenshot with existing public network evidence visuals and link the broader résumé-reported packet-analysis experience to the smaller reproducible fixture. Expand the academic page into a three-image campus gallery using CC BY-SA 3.0 CSUSB photographs.

## Provenance and copy rules

- “Completed experience” is supported by the owner's explicit confirmation, résumé-reported Kali simulations, 5,000+ packets analyzed, Wireshark use and Snort tuning, plus transcript-confirmed penetration-testing and networking courses.
- Existing public fixture counts remain separate: 20 generated packets, 12 decoded observations and two review signals.
- Every image carries one of these truthful scopes: actual portfolio capture, reproducible public artifact, or attributed reference image.
- Missing original screenshots may be acknowledged in a source note but must not turn completed experience back into “proposed” or “not executed” wording.

## Visual direction

Preserve the clean white, charcoal and green portfolio. Add a responsive evidence strip with large imagery, short labels and quiet captions. Use Jack H. Brown Hall and the University Avenue entrance alongside the existing Pfau Library image to give the academic page a stronger sense of place without turning it into a campus brochure.

## Validation

Extend the source-boundary check so it requires completed-experience wording, network coverage and image-scope labels while preserving all existing synthetic fixture boundaries. Run accessibility, link, source, browser and live-response checks, then review desktop and mobile captures once.
