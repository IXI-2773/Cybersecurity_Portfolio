## Optional public badge verification workflow

1. Use your **own** certification issuer account or issuing badge provider. If the corresponding badges appear in **Credly**, review the badge and the name it publicly displays before enabling public sharing.
2. On Credly, open the individual badge and use its **Share** options to obtain a shareable badge page link. If using a public Credly profile instead, copy the profile URL from the account's profile menu. Do not substitute a screenshot of the badge for an independently resolvable record.
3. Decide explicitly whether the name and credential metadata displayed on the shared page are appropriate for publication. **The portfolio display name is Don Lopez; the original issued-to name on a public badge may be different.** Credly states that public badges show the issued-to name and that earners control whether their badges are public.
4. Only after choosing to publish, add the actual badge URLs next to the relevant certifications. Until then, leave the status **owner-reported / not independently verified**. Do not invent issue dates, expiration dates or credential IDs.

Official reference documentation: [Credly badge sharing](https://support.credly.com/hc/en-us/articles/360021222231-How-to-accept-and-manage-your-digital-badge), [sharing a public profile](https://support.credly.com/hc/en-us/articles/360039852511-How-do-I-share-my-profile), and [badge name visibility](https://support.credly.com/hc/en-us/articles/360026919551-Can-I-hide-my-name-from-appearing-within-my-Badge).

A public badge verification URL is optional. Credential claims should remain accurate regardless of whether public verification is enabled.
