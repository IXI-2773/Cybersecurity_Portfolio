01 / REPRODUCIBLE SECURITY EXERCISES

Four public lab investigations.

These are controlled Python exercises with 76 focused tests in total. Passing tests demonstrate their documented training behavior, not production security efficacy.

SPLUNK SCREENSHOT + PYTHON LAB · 31 TESTS

Authentication detection

What the evidence supports: The first 64-event SPL search matched 3/5 expected findings; after an inclusive 600-second correction, a saved native Splunk dashboard screenshot showed all 5/5 expected findings.

What it does not prove: Training cases, not an attack-detection accuracy rate. Indexed ingestion and alert firing were not verified; cropped screenshot does not show the full query/job ID.
