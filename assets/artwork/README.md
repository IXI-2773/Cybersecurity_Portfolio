# Editorial artwork

These images were generated with the built-in image-generation tool for Don
Lopez's portfolio on October 24, 2026. They are conceptual editorial artwork,
not lab screenshots, actual tool interfaces, device photos or evidence artifacts.

The generated PNG originals remain unchanged. Website WebP derivatives preserve
the 1536 × 1024 composition and were encoded at quality 90 without cropping or
resizing. They are displayed with conceptual-art captions or labels.
