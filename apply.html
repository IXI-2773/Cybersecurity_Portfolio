Inside the investigation

What connects the Active Directory activity across hosts?

Same-host parent process GUIDs and logon sessions link remote PowerShell to its host context; matching TCP tuples and timing add network corroboration. A 39.812-second collection delay changes apparent ordering. This is independent analysis of OTRF’s recorded emulation, not an owner-operated capture or production incident. The Python analysis ran; its SPL/Sigma translations remain unexecuted. Inspect the source-linked case ↗

Why did the original Splunk search miss two findings?

Both omitted cases depended on failures exactly 600 seconds before a success. The original streamstats time_window=10m query returned 3/5; the bounded replacement explicitly counted ages 0 through 600 seconds inclusive and the saved Splunk dashboard displayed 5/5 expected synthetic results. Review the discrepancy ↗

Would the five findings justify declaring an incident?

No. These are synthetic authentication events. Even with genuine operational events, confirm source integrity, MFA/session telemetry, account context, potential benign activity, and escalation authority before classifying compromise.

Does four-to-zero mean the web application was secured?

No. Four deliberately introduced rule violations stopped matching the localhost fixture after the changes. Browser enforcement, TLS, real application workflows and independent penetration testing were not established. Read the scope ↗
