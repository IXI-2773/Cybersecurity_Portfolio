# Security and responsible disclosure

This repository is a **static personal portfolio** and includes a deliberately **synthetic** login detection lab. It is not a production monitoring service and contains no real account logs.

Please do not submit real credentials, API tokens, personal data, proprietary source, or private repository material in issues or pull requests. If you identify a security issue, contact the maintainer via GitHub account contact channels without posting sensitive exploit details publicly.

Celestial Resonance and Research AI Infrastructure are separate private projects; their inclusion here is descriptive only and does not authorize disclosure of their source or access to their systems.

The demonstration's reserved documentation IP addresses are not targets to investigate.
