Source, reproducibility, and receipt details

The browser fixture is generated from the public CSV and frozen expected findings. Their SHA-256 values are included in a downloaded receipt, along with the engine version, run times, and calculated results.

Run receipts are snapshots. Changing a control does not rerun it. Downloads include the last completed baseline and any completed replay or coverage run.
