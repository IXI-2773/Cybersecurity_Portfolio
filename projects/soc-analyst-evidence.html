HOW I INVESTIGATE

A detector match is a lead, not a verdict.

Validate source/time and predicate → scope affected assets → seek independent corroboration → challenge with benign explanations → document provisional severity and uncertainty → hand off only authorized actions.

Read analyst workflow → SOC triage playbook ↗ Interview evidence brief ↗ Recruiter overview ↗

All exercises use fabricated inputs or localhost-only toy fixtures. ATT&CK mappings describe investigative hypotheses. No real intrusion, security product deployment or external security testing is claimed.
