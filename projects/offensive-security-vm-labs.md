## Transferable workflow

1. Isolate the deliberately vulnerable target and confirm authorized scope.
2. Enumerate services and application behavior before forming a test path.
3. Validate only the lab's intended path.
4. Document observations, decisions and the telemetry a defender could review.

The portfolio's [generated packet investigation](network-traffic-analysis.md), [Windows process triage](windows-process-triage.md), and [Splunk authentication case](authentication-detection.md) provide current, reproducible evidence for the defensive side of that workflow.
